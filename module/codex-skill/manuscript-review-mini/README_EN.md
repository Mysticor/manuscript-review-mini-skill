# Manuscript Review Mini

Review a complete manuscript with two independent reviewers, one issue ledger,
minimal necessary revisions, risk-triggered fresh review, optional language edits,
and evidence-preserving publication handoff. See SKILL.md for the active workflow.
Legacy full-mode projects retain their original checks; they are not silently downgraded.

Use Python 3.11+ and the repository requirements. Nature specialist instructions are
bundled under module/vendor; installed overrides are optional. Other workflow stages
are separately installed. Missing specialists must be reported, not simulated.

Synthetic regression fixtures include legacy full-mode cases. Their mock approval and
review records are test material, not a claim that new independent reviews were performed.
See the repository README for portable test commands and optional integration tests.
