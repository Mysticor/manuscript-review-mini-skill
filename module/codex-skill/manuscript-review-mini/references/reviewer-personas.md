# Reviewer Personas

A domain expert lens: problem importance, gap/novelty against canon, interpretation,
limits, scientific/engineering relevance. B methods/evidence lens: correctness,
controls/baselines, leakage, reproducibility, uncertainty, claim-dependent validation.
C editorial/target-audience lens: fit/significance, positioning, story clarity,
length/completeness and display evidence chain. Generic journal is not flagship Nature.
Reviews change A to synthesis/taxonomy, B to inclusion/coverage/bias/conflicting sources,
C to organizing value for intended audience. Perspectives audit reasoned argument and
source boundaries rather than demanding experiments. These are emphases, not identities.
