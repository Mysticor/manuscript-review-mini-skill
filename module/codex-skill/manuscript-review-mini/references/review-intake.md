# Review Intake

Create a separate review directory, immutable input_snapshot of the Stage 2 draft,
assets, captions, references, blueprint and source-verification, with checksums.
Work on reviewed_manuscript.md, reviewed_supplementary.md and copied assets inside
review; never overwrite Stage 2. Default review/ beside manuscript.md; avoid recursive
copy of existing review. Explicit equivalent layouts can be adapted with documented
file mapping. Do not trust a marker alone. Read manuscript, sections, claims/displays,
SI (or reasoned not-required), references and unresolved placeholders. An incomplete
Stage 2 returns REQUIRES_STAGE2_REVISION, not a formal reviewer round.
Actual source data > Stage 1 ACTUAL facts > Stage 2 blueprint > current prose.
Read inputs/handoff or supplied MANUSCRIPT_HANDOFF for results, claims, methods,
statistics, canon, novelty, limitations and provenance. Planned hypotheses never
supersede ACTUAL outcomes. If facts disagree with raw source, reopen/reanalyse source;
do not bless a convenient value. Real mock inputs are explicitly test-only.
