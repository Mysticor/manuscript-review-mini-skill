# Figure Table Audit

For each main display assess purpose, claim, each panel's role, redundancy/missing
support, standalone caption, faithful prose interpretation, scale/normalization,
statistics/provenance, and information lost if removed. DATA: axes, units, uncertainty,
legend, comparison fairness and sample meaning. PHOTOS: actual source, processing,
scale/ROI/arrows and experiment link. MODEL OUTPUT: actual output, selection/failures,
quantitative support. LITERATURE: original panel/source and verified meaning, rights,
attribution; adapted/synthesized concepts must not turn inference into consensus.
Table rows/columns, units/precision, values, fair highlights/comparators, missing values,
statistics and duplication need checking; review tables keep per-cell source provenance.
Finite label/alignment/legend repairs use nature-figure, keeping real data unchanged.
Major display redesign routes targeted Stage 2; never rerun all writing. No cosmetic
change may conceal adverse cases or magnify effects. Keep editable sources and hashes.
