# 中文终稿审阅副本

每次交付排版前内容终稿，同时提供与当前正式稿对应的完整中文审阅稿。放在研究项目 `author_review/reviewed_manuscript_zh.md`；有实质补充材料时一并提供 `reviewed_supplementary_zh.md`。保留正式原语种稿为唯一投稿内容母版，中文稿是方便作者审阅的对照副本，不默认替代排版输入。原稿本身为中文时直接复用已核验的中文终稿；如尚未应用humanizer，按以下方式生成并核对审阅副本，不为凑文件重复翻译。

先核实原稿已达到现有审稿就绪要求，再逐节忠实译为中文，实际读取当前安装的 `humanizer/SKILL.md` 并以文件/嵌入模式处理中文表达。保持学术语气、技术术语和作者声音，不把humanizer当作翻译或科学审查引擎。仅调整表达，不能为去除AI痕迹删掉事实、限定条件、局限或证据。若发现源文可疑，列为待核对意见，不擅自改写科学含义。Humanizer缺失或无法读取时明确标记未完成，不声称已调用。

覆盖标题、摘要、全部正文、图注、表题/表注、表中解释性文字及有实质内容的补充材料；保留原章节顺序、图表编号、公式编号、变量、数值、单位、统计口径、引文键/编号和参考文献对应关系。参考文献题名、作者、DOI等书目信息原样保留，不伪造中文出版条目。图件复用原资产和相对链接，图内文字需要解释时放在对应中文图注/说明中，不重画或改动科学图件。必要专业词首次附原文；不写成摘要、缩写版或科普改写。

完成后逐节对照，检查遗漏、否定/因果/程度、研究对象、独立样本/重复测量、实测/模拟、比较基线、数字、公式及引用对应。任何语义漂移先修正；数字匹配或脚本PASS不能替代语义核验。文件只保存最终中文文本，不附humanizer草稿或AI痕迹点评。作者审阅稿的说明可置于文首，标注用途、对应正式稿相对路径、版本及SHA256；源稿或图表改变时只更新受影响内容并重新核对，不沿用过期“已核验”状态。

在现有 `qa/combined_audit.md` 与 `resume.md` 记中文副本路径、对应源版本/哈希、humanizer实际执行情况、覆盖和一致性检查结论及未完成项，不新建科学台账。缺少内容或工具时可交付标明缺口的审阅草稿，但不能宣称中文终稿已完成。原有科学READY与中文审阅副本完成情况分别如实报告，脚本finalize不会自动生成、检查或认证中文翻译。

终稿交付时同时给原语种稿和中文稿链接，说明等待作者排版前审阅。沿用原有阶段停止点，不新增技术Gate；作者反馈若改变科学内容，先修改正式母版、按原风险规则重新核验，再更新中文副本和排版交接。明确授权进入排版后才接续第四阶段；不能只改中文稿便把修改当成正式稿已更新。

中文副本随作者交付材料单独提供，不混作PUBLICATION_HANDOFF中的canonical稿或投稿文件，不要求更改既有package格式。交接说明注明其路径、对应版本和作者反馈是否已经处理；正式排版始终使用已核验的canonical稿。
