# Revision Routing

STAGE3_LOCAL: overclaim wording, local paragraph/interpretation, citation placement,
caption or terminology. STAGE2: section/story/evidence sequence, panel recomposition,
table→figure or synthesis redesign. Use manuscript-writing/nature-writing/nature-figure
for only the affected item, then return; state REQUIRES_STAGE2_REVISION until resolved.
STAGE1: missing experiment/data/external validation/source necessary to central claim,
state REQUIRES_NEW_EVIDENCE and research-planning execution handback. Never generate
substitute evidence. Record explicit routing in triage; scripts validate routing, not
infer it from keywords. All major scientific scope/claim/journal changes need user decisions.
