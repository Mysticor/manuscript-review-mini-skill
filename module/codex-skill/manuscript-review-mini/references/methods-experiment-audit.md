# Methods Experiment Audit

Check actual method, preprocessing, parameters, software/hardware as relevant,
model selection/tuning and leakage, reproducibility, fair baselines/controls. For each
central claim decide whether decisive experiment, ablation, external/OOD validation,
robustness, sensitivity, failure cases or negative evidence is required. Do not demand
every test for every paper. Map required evidence to ACTUAL results. Missing essential
observations returns REQUIRES_NEW_EVIDENCE; wording cannot supply data. Existing-data
reanalysis needs a correction plan, reproducible code and new provenance, never a silent
edit to frozen facts. Preserve source version and record why corrected facts supersede it.
