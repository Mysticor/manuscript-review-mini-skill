# Comment Triage

Freeze Round 1 first. Triage each stable comment ID with reviewer, section, issue,
severity BLOCKER/MAJOR/MODERATE/MINOR/OPTIONAL, confidence, ACCEPT/PARTIALLY_ACCEPT/
REJECT/AUTHOR_DECISION, action/routing/assets/decision need/status. Preserve the original
comment and source pointers. REJECT must explain evidence, reasoning/trade-off and any
useful clarification; unrelated Experiment X can be rejected, never blindly obeyed.
PARTIALLY_ACCEPT must specify accepted and excluded parts. Severity reflects validity,
interpretation, reproducibility, novelty, acceptance or readability, not rhetoric.
Do not turn a true central concern into minor for convenience. All resolved major items
need an inspectable resolution record. Both rounds use issues.csv with unique IDs; record any new Round2 issues in that same ledger.
