# Statistics Audit

Route relevant reporting/analysis concerns to nature-statistics with actual design
and data. Audit experimental unit, n versus technical replicates, repeats/seeds,
effect/uncertainty, CI/test assumptions, multiple comparisons, missing values/outliers,
p-value interpretation and practical versus statistical significance. A single ML run
cannot establish stability. Reanalysis from existing data can resolve a concern with
traceable outputs; absent necessary data means REQUIRES_NEW_EVIDENCE. Document reasoned
N/A for conceptual review/perspective, not invented tests or blanket statistical demands.
